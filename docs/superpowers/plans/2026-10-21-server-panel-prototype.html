Prototype statis untuk review. Bukan kode aplikasi: ubah tombol di bawah untuk melihat layar, state, peran, dan perilaku panel. Tidak ada yang tersambung ke server.

Cara membaca
  • Desktop (1280): sidebar 250 + konten + panel kanan 288 px (sticky, scroll sendiri). Tombol "Hide" menyembunyikan panel dan memunculkan widget mengambang.
  • Tablet (1000): tidak muat tiga kolom. Panel menjadi drawer kanan yang dibuka dari pil status di header; saat tertutup, widget mengambang tampil.
  • Phone (375): header = Menu, judul, pil, Logout (ikon). Kredit admin menjadi baris pertama drawer.
  • Panel, urutan atas ke bawah: state, peringatan/progres, tiga angka utama, aksi utama (Start/Extend), ringkasan boot (stepper + kalimat + tombol "View log"), detail, lalu Danger zone sebagai section sendiri di dasar panel (Destroy + instance tak terlacak), selalu terlihat.
  • Boot log: tidak lagi di kolom tengah. "View log" membuka dialog layar penuh (di HP memenuhi layar) berisi log, Pause, Copy, Clear, Download. Admin saja.
  • Dialog Start (tidak digambar): menampilkan peringatan kalau kredit lebih kecil dari estimasi biaya maksimum.
  • Member: melihat state, angka, dan widget; tanpa kredit, aksi, console, dan footer bahaya.
